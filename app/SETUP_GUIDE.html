1 Pré-requisitos e instalação do ambiente
O que já está prontoCódigo-fonte completo, firebase_options.dart gerado com chaves reais do projeto desafog-ai.

Ferramentas necessárias

  • Flutter SDK ≥ 3.11.4 — flutter.dev/get-started/install
  • Node.js ≥ 18 — nodejs.org
  • Vercel CLI — npm i -g vercel
  • Firebase CLI — npm i -g firebase-tools
  • FlutterFire CLI — dart pub global activate flutterfire_cli
  • Android Studio (build Android) ou Xcode (build iOS)

Instalar dependências

cd E:\Projetos\Desafog.ai && flutter pub get
cd bot && npm install
flutter doctor -v   # resolva todos os itens [X]
2 Configurar o projeto Firebase Parcialmente pronto
Boas notícias! firebase_options.dart já contém as chaves reais do projeto desafog-ai.

Ainda precisa fazer no console.firebase.google.com → projeto desafog-ai

  • Ativar Authentication: Sign-in method → Email/Senha + Google → Ativar
  • Criar Firestore: Firestore Database → Criar → Modo produção → southamerica-east1
  • Aplicar regras de segurança (ver Seção 7)
  • Gerar service account: Configurações → Contas de serviço → Gerar nova chave privada → salve o JSON
Nunca commite o service-account.json! Adicione ao .gitignore.

6 Configurar Google Sign-In Manual

Firebase Console

  • Authentication → Sign-in method → Google → Ativar → informe e-mail de suporte → Salvar
  • Authentication → Settings → Authorized domains → adicione seu domínio de produção

SHA-1 para Android (Google Sign-In)

# Windows PowerShell
keytool -list -v -keystore "$env:USERPROFILE\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android

Copie o SHA-1 → Firebase → Configurações → Android → Adicionar impressão digital

7 Regras de segurança do Firestore Manual

Firestore Database → Regras → substitua e clique em Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /link_codes/{codeId} {
      allow create: if request.auth != null
                    && request.resource.data.uid == request.auth.uid;
      allow read: if false;
    }
    match /telegram_links/{chatId} {
      allow read, write: if false;
    }
  }
}
8 Criar e configurar o bot do Telegram Manual

Criar via @BotFather

  • Telegram → busque @BotFather → envie /newbot
  • Nome: Desafog.ai · Username: desafog_ai_bot
  • Copie o token: 1234567890:ABC-DEF...

Gerar service account em Base64

# PowerShell — copia resultado para a área de transferência
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\caminho\service-account.json")) | clip

Arquivo bot\.env

cd E:\Projetos\Desafog.ai\bot && copy .env.example .env
TELEGRAM_BOT_TOKEN=token_do_botfather
GEMINI_API_KEY=sua_chave_gemini
FIREBASE_SERVICE_ACCOUNT_BASE64=string_base64
WEBHOOK_SECRET=string_aleatoria_segura
9 Deploy do bot no Vercel Manual
vercel login   # primeira vez
cd E:\Projetos\Desafog.ai\bot
vercel env add TELEGRAM_BOT_TOKEN
vercel env add GEMINI_API_KEY
vercel env add FIREBASE_SERVICE_ACCOUNT_BASE64
vercel env add WEBHOOK_SECRET
vercel --prod

Anote a URL gerada — ex.: https://desafog-telegram-bot.vercel.app

11 Build Android Manual

Confirme que android/app/google-services.json existe (gerado pelo FlutterFire CLI).

Keystore para release (uma vez só)

keytool -genkey -v -keystore desafog-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias desafog

Crie android/key.properties:

storePassword=SUA_SENHA
keyPassword=SUA_SENHA
keyAlias=desafog
storeFile=C:/caminho/desafog-release.jks
flutter build apk --debug          # teste
flutter build appbundle --release  # Play Store
key.properties e .jks já estão no .gitignore. Nunca os commite.

14 Notificações — Windows Developer Mode Opcional

Notificações funcionam nativamente em Android, iOS, macOS e Linux. No Windows é necessário:

  • Configurações → Sistema → Para desenvolvedores → Modo Desenvolvedor → Ativado
  • Reiniciar o Windows → flutter run -d windows
Sem Developer Mode: o app funciona normalmente no Windows; apenas lembretes de notificação local não aparecem.
